# Field & Form cart

A Flask shopping cart built from the `ShoppingCart` class in `E CART.PY`. The web app keeps cart data in the Flask session and includes a small product catalog, quantity updates, coupon `2005` for 10% off, and checkout feedback.

## Run

```powershell
cd "E cart"
python -m pip install -r requirements.txt
python app.py
```

Open `http://127.0.0.1:5000` in a browser.
